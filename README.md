# Índigo — Inscrições

Página de inscrição para o **Índigo**, um evento de aulas. A pessoa vê a grade de aulas, escolhe as que quer fazer e envia o comprovante de pagamento pelo próprio formulário.

## Funcionalidades

- Grade de aulas com horário e professor
- Seleção das aulas desejadas (avulsas ou combo completo)
- Instruções de pagamento via Pix
- Envio do comprovante junto com a inscrição

## Tecnologias

- [Next.js](https://nextjs.org) (App Router) e React
- TypeScript
- Tailwind CSS

## Como rodar

```bash
npm install
npm run dev
```

Depois, abra o endereço local `localhost:3000` no navegador.
